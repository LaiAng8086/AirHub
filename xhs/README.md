# AirHub XHS text adapter

This directory contains only the no-login, text-only functionality required by
AirHub. It resolves supported XHS post URLs, reads the public page's initial
state, and saves title/author/timestamps/tags/description. It never reads browser
cookies and never downloads images, video, or live media.

The adapter is derived from XHS-Downloader 2.11 beta. See `LICENSE` and the root
`THIRD_PARTY_NOTICES.md` for attribution and license terms. Use it only for
content you are permitted to access and archive.
